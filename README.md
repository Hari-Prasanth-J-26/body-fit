# 💪 Body‑Fit — React Fitness & Workout Web App

A modern, responsive **fitness & workout planner web application** built with **React.js** and **Tailwind CSS**, focused on clean UI, fast performance, and component‑based architecture.

🌐 **Live Demo:** [https://body-fit-gym-webapp.netlify.app/](https://body-fit-gym-webapp.netlify.app/)

---

## 🧠 About the Project

**Body‑Fit** is a frontend fitness web app that helps users explore workouts and browse fitness‑related sections using a simple and elegant UI.

This project demonstrates:

* Reusable & modular React components
* Responsive design using Tailwind utility classes
* Clean folder structure for scalability
* Fast development setup powered by **Vite**

## ⚙️ Getting Started

Follow the steps below to run the project locally.

### Prerequisites

* Node.js (LTS recommended)
* npm / yarn / pnpm

Check version:

```bash
node -v
npm -v
```

---

### Installation

```bash
git clone https://github.com/Hari-Prasanth-J-26/body-fit.git
cd body-fit
npm install
```

---

### Run Locally

```bash
npm run dev
```

Then open in browser:

```
http://localhost:5173
```

## 🗂 Project Structure

```
body-fit/
 ├─ src/
 │  ├─ components/
 │  ├─ pages/
 │  ├─ assets/
 │  └─ App.jsx
 ├─ public/
 ├─ index.html
 ├─ package.json
```

* `components/` → UI components
* `pages/` → Page‑level components
* `assets/` → Images & static files

## 🚢 Deployment

This project is deployed on **Netlify**.

1. Push latest changes to `main`

Or deploy manually using CLI.
